# Migrations numeradas antigas (arquivo)

Os 17 arquivos numerados foram preservados fora de `supabase/migrations` para que o Supabase CLI não os interprete como migrations pendentes.

Eles são cópias do histórico local anterior e servem apenas como referência de auditoria. Não presuma que cada arquivo seja idêntico às migrations timestamped ou ao SQL atualmente aplicado em produção: as versões devem ser comparadas individualmente antes de qualquer reutilização.

As migrations canônicas aplicadas em produção ficam em `supabase/migrations`. Não mova estes arquivos de volta para essa pasta nem os aplique novamente.
